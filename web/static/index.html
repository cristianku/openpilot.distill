                  On your comma

                    Install this model

                    It takes the place of openpilot's driving model and the comma restarts; the first start takes a few extra minutes while the comma prepares the model. The comma must be parked, with the Models menu on Default.

                    Put the original model back

                    openpilot's own driving model comes back and the comma restarts. A software update from the comma screen does the same.

                    On Hugging Face

                    Shares the model in your Hugging Face repository, where sunnypilot offers it in the comma's Models menu. A dry run comes first: it prepares the model and checks it on the comma without uploading anything. If it succeeds, Publish uploads it after you confirm the name.

                    Hugging Face is not connected: connect it in Settings to publish.
